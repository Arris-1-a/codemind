கோட்மைண்ட் என்பது உங்கள் மேம்பாட்டு பணிப்பாய்வுகளை நெறிப்படுத்த வடிவமைக்கப்பட்ட ஒரு விரிவான AI-இயங்கும் மேம்பாட்டு கருவித்தொகுப்பாகும். இது பல AI வழங்குநர்களுடன் (OpenAI, Anthropic, DeepSeek, உள்ளூர் மாதிரிகள்) ஒருங்கிணைந்து புத்திசாலித்தனமான குறியீடு மதிப்பாய்வு, தானியங்கி PR மேலாண்மை, குறியீடு உருவாக்கம் மற்றும் ஆவணப்படுத்தல் ஆட்டோமேஷன் ஆகியவற்றை வழங்குகிறது.
## ✨ அம்சங்கள் / 功能特性
### 🔍 AI குறியீடு விமர்சனம் / AI 代码审查
- ** பாதுகாப்பு ஸ்கேனிங்** - கடின குறியிடப்பட்ட ரகசியங்களைக் கண்டறியவும், SQL ஊசி, XSS, பாதை டிராவர்சல்
- **செயல்திறன் பகுப்பாய்வு** - ஒத்திசைவு செயல்பாடுகள், நினைவக கசிவுகள், திறமையற்ற வடிவங்களை அடையாளம் காணவும்
- **குறியீடு வாசனை கண்டறிதல் ** - கொடி நீண்ட செயல்பாடுகள், ஆழமான கூடு, மேஜிக் எண்கள்
- ** சிறந்த நடைமுறைகள் ** - TypeScript வகைகள், பிழை கையாளுதல், பெயரிடும் மரபுகளை செயல்படுத்தவும்
- **SARIF ஆதரவு** - தொழில்-தரமான வடிவத்தில் ஏற்றுமதி முடிவுகள்
### 📝 PR உதவியாளர் / PR 助手
- ** கிட் டிஃப் இலிருந்து PR விளக்கங்களை தானாக உருவாக்கவும் **
- ** ஆபத்து மதிப்பீட்டுடன் மாற்றங்களின் ஸ்மார்ட் சுருக்கம் **
- ** இன்லைன் பரிந்துரைகளுடன் தானியங்கி PR விமர்சனம் **
- **வாக்கரை மாற்றவும் ** - மாற்றங்கள் மூலம் முறையாக செல்லவும்







### ⚡ குறியீடு உருவாக்கம் / 代码生成
- ** டெம்ப்ளேட் இயந்திரம் ** - மாறிகள் மற்றும் தர்க்கத்துடன் நீட்டிக்கக்கூடிய குறியீடு வார்ப்புருக்கள்
- **ஸ்பெக் பாகுபடுத்தி ** - பாகுபடுத்தவும் JSON/YAML/இயற்கை மொழி விவரக்குறிப்புகள்
- ** குறியீடு பில்டர் ** - TypeScript, JavaScript, Python மற்றும் பலவற்றை உருவாக்கவும்
- **உள்ளமைக்கப்பட்ட வார்ப்புருக்கள் ** - செயல்பாடுகள், வகுப்புகள், இடைமுகங்கள், எதிர்வினை கூறுகள்
### 📚 ஆவணப்படுத்தல் ஆட்டோமேஷன் / 文档自动化
- **API ஆவணம் தலைமுறை** - மூலத்திலிருந்து JSDoc மற்றும் வகைகளை பிரித்தெடுக்கவும்
- **README ஜெனரேட்டர்** - மெட்டாடேட்டாவிலிருந்து தொழில்முறை READMEகளை உருவாக்கவும்
- **சேஞ்ச்லாக் ஜெனரேட்டர்** — கிட் வரலாற்றில் இருந்து சேஞ்ச்லாக்களை உருவாக்கவும்
- **பல வடிவ வெளியீடு ** - மார்க்டவுன், HTML, JSON
### 🔗 GitHub ஒருங்கிணைப்பு / GitHub 集成
- **Webhook handler ** — செயல்முறை GitHub நிகழ்வுகள்
- **GitHub செயல்கள்** - பயன்படுத்த தயாராக உள்ள CI பணிப்பாய்வுகள்
- **GitHub ஆப்** - நிரல் API அணுகல்
