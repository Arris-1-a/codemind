# 🧠 Codemind
**Assistant de développement alimenté par l’IA — Revue de code, analyse de relations publiques, génération de code, automatisation de la documentation**

[! [Très animé](https://img.shields.io/badge/test-vitest-green)](https://vitest.dev/)
🧠 > Intelligent Development Assistant — Outils de revue de code, analyse PR, génération de code et automatisation documentaire pilotés par IA
Codemind est une boîte à outils complète alimentée par l’IA conçue pour simplifier votre flux de travail de développement. Il s’intègre avec plusieurs fournisseurs d’IA (OpenAI, Anthropic, DeepSeek, modèles locaux) pour fournir une revue intelligente de code, une gestion automatisée des relations publiques, la génération de code et l’automatisation de la documentation.
## ✨ Caractéristiques / 功能特性
### 🔍 AI Code Review / AI 代码审查
- **Analyse de sécurité** — détection de secrets codés en dur, injection SQL, XSS, parcours de chemin
- **Analyse des performances** — identifier les opérations de synchronisation, les fuites de mémoire, les schémas inefficaces
- **Code détecte la détection** — signale les fonctions longues, nidification profonde, nombres magiques
- **Meilleures pratiques** — imposer les types TypeScript, la gestion des erreurs, les conventions de nommage
- **Soutien SARIF** — résultats d’exportation au format standard industriel
### 📝 PR Assistant / PR 助手
- **Générer automatiquement des descriptions PR** à partir de git diff
- **Résumé intelligent** des changements avec l’évaluation des risques
- **Examen automatisé des relations publiques** avec suggestions en ligne
- **Marcheur de changement** — navigue systématiquement à travers les changements







### ⚡ Génération de code / 代码生成
- **Moteur de modèles** — modèles de code extensibles avec variables et logique
- **Analyseur spéculatif** — analyse des spécifications JSON/YAML/langage naturel
- **Constructeur de code** — générer TypeScript, JavaScript, Python, et plus encore
- **Modèles intégrés** — fonctions, classes, interfaces, composants React
### 📚 Documentation Automation / 文档自动化
- **Génération de documents API** — extraire JSDoc et types à partir de la source
- **Générateur README** — crée des README professionnels à partir de métadonnées
- **Générateur de journaux de modifications** — compilation des journaux de modifications à partir de l’historique git
- **Sortie multi-format** — Markdown, HTML, JSON
### 🔗 Intégration GitHub / GitHub 集成
- **Gestionnaire Webhook** — traiter les événements GitHub
- **GitHub Actions** — flux de travail CI prêts à être utilisés
- **GitHub App** — accès programmatique à l’API
