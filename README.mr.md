कोडमाइंड हे एक व्यापक एआय-समर्थित विकास टूलकिट आहे जे आपल्या विकास कार्यप्रवाहाला सुव्यवस्थित करण्यासाठी डिझाइन केलेले आहे. हे बुद्धिमान कोड पुनरावलोकन, स्वयंचलित पीआर व्यवस्थापन, कोड निर्मिती आणि दस्तऐवजीकरण ऑटोमेशन प्रदान करण्यासाठी एकाधिक एआय प्रदात्यांसह (ओपनएआय, अँथ्रोपिक, डीपसीक, स्थानिक मॉडेल्स) समाकलित करते.
## ✨ Features / 功能特性
### 🔍 AI Code Review / AI 代码审查
- **सुरक्षा स्कॅनिंग** - हार्डकोडेड रहस्ये, एसक्यूएल इंजेक्शन, एक्सएसएस, पथ ट्रॅव्हर्सल शोधा
- **कार्यप्रदर्शन विश्लेषण** - सिंक ऑपरेशन्स, मेमरी लीक, अकार्यक्षम नमुने ओळखा
- **कोड गंध शोधणे** - ध्वज लांब कार्ये, खोल घरटे बांधणे, जादूचे क्रमांक
- **सर्वोत्तम पद्धती** - टाइपस्क्रिप्ट प्रकार, त्रुटी हाताळणे, नामकरण परंपरा लागू करा
- **SARIF समर्थन** - उद्योग-मानक स्वरूपात निर्यात परिणाम
### 📝 PR Assistant / PR 助手
- **गिट डिफ वरून पीआर वर्णन स्वयंचलितपणे व्युत्पन्न करा**
- **जोखीम मूल्यांकनासह बदलांचे स्मार्ट सारांश**
- **स्वयंचलित पीआर पुनरावलोकन** इनलाइन सूचनांसह
- **वॉकर बदला** - बदलांमधून पद्धतशीरपणे नेव्हिगेट करा







### ⚡ Code Generation / 代码生成
- **साचा इंजिन** — व्हेरिएबल्स आणि लॉजिकसह एक्स्टेंसिबल कोड टेम्पलेट्स
- **स्पेक पार्सर** — JSON/YAML/नैसर्गिक भाषा चष्मा यांचे विश्लेषण करा
- **कोड बिल्डर** - टाइपस्क्रिप्ट, जावास्क्रिप्ट, पायथन आणि बरेच काही व्युत्पन्न करा
- **अंगभूत साचे** - कार्ये, वर्ग, इंटरफेस, प्रतिक्रिया घटक
### 📚 Documentation Automation / 文档自动化
- **एपीआय डॉक जनरेशन** - स्रोतातून जेएसडीओसी आणि प्रकार काढा
- **README जनरेटर** - मेटाडेटामधून व्यावसायिक READMEs तयार करा
- **चेंजलॉग जनरेटर** - गिट इतिहासातून चेंजलॉग तयार करा
- **मल्टी-फॉरमॅट आउटपुट** — मार्कडाउन, एचटीएमएल, जेएसओएन
### 🔗 GitHub इंटिग्रेशन / GitHub 集成
- **वेहूक हँडलर** - गिटहब इव्हेंटवर प्रक्रिया करा
- **गिटहब क्रिया** - वापरण्यास तयार सीआय वर्कफ्लो
- **गिटहब अ ॅप** - प्रोग्रामॅटिक एपीआय प्रवेश
