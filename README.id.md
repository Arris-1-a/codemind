# 🧠 Codemind
**Asisten Pengembangan Bertenaga AI — Tinjauan Kode, Analisis PR, Pembuatan Kode, Otomasi Dokumentasi**
[! [Lisensi: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LISENSI)
[! [TypeScript](https://img.shields.io/badge/TypeScript-5.5-blue)](https://www.typescriptlang.org/)
[! [pnpm](https://img.shields.io/badge/pnpm-9-orange)](https://pnpm.io/)
[! [Vitest](https://img.shields.io/badge/test-vitest-green)](https://vitest.dev/)
🧠 > Intelligent Development Assistant — alat tinjauan kode, analisis PR, pembuatan kode, dan otomasi dokumen berbasis AI
Codemind adalah toolkit pengembangan berbasis AI yang komprehensif dan dirancang untuk memperlancar alur kerja pengembangan Anda. Aplikasi ini terintegrasi dengan berbagai penyedia AI (OpenAI, Anthropic, DeepSeek, model lokal) untuk menyediakan tinjauan kode cerdas, manajemen PR otomatis, pembuatan kode, dan otomatisasi dokumentasi.
## ✨ Fitur / 功能特性
### 🔍 Ulasan Kode AI / AI 代码审查
- **Pemindaian keamanan** — mendeteksi rahasia yang dikodekan secara hardcode, injeksi SQL, XSS, traversal jalur
- **Analisis kinerja** — mengidentifikasi operasi sinkronisasi, kebocoran memori, pola yang tidak efisien
- **Kode mencium deteksi** — fungsi panjang tanda, sarang dalam, angka ajaib
- **Praktik terbaik** — menegakkan tipe TypeScript, penanganan kesalahan, konvensi penamaan
- **Dukungan SARIF** — hasil ekspor dalam format standar industri
### 📝 Asisten PR / Asisten PR
- **Menghasilkan deskripsi PR secara otomatis** dari git diff
- **Ringkasan cerdas** perubahan dengan penilaian risiko
- **Tinjauan PR otomatis** dengan saran inline
- **Perubahan walker** — menavigasi perubahan secara sistematis







### ⚡ Pembuatan Kode / 代码生成
- **Mesin template** — template kode yang dapat diperluas dengan variabel dan logika
- **Spec parser** — parse spesifikasi JSON/YAML/bahasa alami
- **Pembuat kode** — menghasilkan TypeScript, JavaScript, Python, dan lainnya
- **Template bawaan** — fungsi, kelas, antarmuka, komponen React
### 📚 Otomatisasi Dokumentasi / 文档自动化
- **API doc generation** — ekstrak JSDoc dan tipe dari sumber
- **README generator** — membuat README profesional dari metadata
- **Generator changelog** — membangun changelog dari riwayat git
- **Output multi-format** — Markdown, HTML, JSON
### 🔗 Integrasi GitHub / GitHub 集成
- **Handler Webhook** — memproses event GitHub
- **GitHub Actions** — alur kerja CI siap pakai
- **Aplikasi GitHub** — akses API programatik
