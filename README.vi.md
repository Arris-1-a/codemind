# 🧠 Codemind
**Trợ lý Phát triển được hỗ trợ bởi AI — Xem xét mã, Phân tích PR, Tạo mã, Tự động hóa tài liệu**

[! [Vitest](https://img.shields.io/badge/test-vitest-green)](https://vitest.dev/)
🧠 > Trợ lý Phát triển Thông minh — Công cụ kiểm tra mã, phân tích PR, tạo mã và tự động hóa tài liệu dựa trên AI
Codemind là bộ công cụ phát triển toàn diện được hỗ trợ bởi AI, được thiết kế để tối ưu hóa quy trình phát triển của bạn. Nó tích hợp với nhiều nhà cung cấp AI (OpenAI, Anthropic, DeepSeek, các mô hình địa phương) để cung cấp việc xem xét mã thông minh, quản lý PR tự động, tạo mã và tự động hóa tài liệu.
## ✨ Tính năng / 功能特性
### 🔍 Đánh Giá Mã AI / AI 代码审查
- **Quét bảo mật** — phát hiện bí mật mã cứng, chèn SQL, XSS, duyệt đường dẫn
- **Phân tích hiệu suất** — xác định các thao tác đồng bộ, rò rỉ bộ nhớ, các mẫu không hiệu quả
- **Phát hiện mã mùi** — đánh dấu hàm dài, lồng sâu, số ma thuật
- **Thực tiễn tốt nhất** — thực thi các kiểu TypeScript, xử lý lỗi, quy ước đặt tên
- **Hỗ trợ SARIF** — kết quả xuất theo định dạng tiêu chuẩn ngành
### 📝 Trợ lý PR / PR 助手
- **Tự động tạo mô tả PR** từ git diff
- **Tóm tắt thông minh** các thay đổi kèm theo đánh giá rủi ro
- **Xem xét PR tự động** kèm gợi ý nội tuyến
- **Change walker** — điều hướng có hệ thống qua các thay đổi







### ⚡ Tạo mã / 代码生成
- **Template engine** — mẫu mã mở rộng với biến và logic
- **Spec parser** — phân tích JSON/YAML/natural language specs
- **Trình tạo mã** — tạo TypeScript, JavaScript, Python và nhiều hơn nữa
- **Mẫu tích hợp** — hàm, lớp, giao diện, thành phần React
### 📚 Documentation Automation / 文档自动化
- **Tạo tài liệu API** — trích xuất JSDoc và các loại từ mã nguồn
- **Trình tạo README** — tạo README chuyên nghiệp từ siêu dữ liệu
- **Trình tạo nhật ký thay đổi** — nhật ký thay đổi xây dựng từ lịch sử git
- **Đầu ra đa định dạng** — Markdown, HTML, JSON
### 🔗 Tích hợp GitHub / GitHub 集成
- **Webhook handler** — xử lý các sự kiện GitHub
- **GitHub Actions** — quy trình làm việc CI sẵn sàng sử dụng
- **Ứng dụng GitHub** — truy cập API lập trình
