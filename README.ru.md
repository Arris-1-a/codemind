# 🧠 Codemind
**Помощник разработчика на базе ИИ — обзор кода, PR-анализ, генерация кода, автоматизация документации**
[! [Лицензия: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](ЛИЦЕНЗИЯ)
[! [TypeScript](https://img.shields.io/badge/TypeScript-5.5-blue)](https://www.typescriptlang.org/)
[! [ПНПМ](https://img.shields.io/badge/pnpm-9-orange)](https://pnpm.io/)
[! [Viest](https://img.shields.io/badge/test-vitest-green)](https://vitest.dev/)
🧠 > Intelligent Development Assistant — инструменты для проверки кода, PR-анализа на базе ИИ, генерации кода и автоматизации документов
Codemind — это комплексный набор инструментов для разработки на базе искусственного интеллекта, созданный для оптимизации вашего рабочего процесса. Он интегрируется с несколькими поставщиками ИИ (OpenAI, Anthropic, DeepSeek, локальные модели) для обеспечения интеллектуального обзора кода, автоматизированного управления PR, генерации кода и автоматизации документации.
## ✨ Особенности / 功能特性
### 🔍 AI Code Review / AI 代码审查
- **Сканирование безопасности** — обнаружение жёстко закодированных секретов, инъекции SQL, XSS, обхода пути
- **Анализ производительности** — выявление операций синхронизации, утечек памяти, неэффективных паттернов
- **Код чувствует обнаружение** — отмечает длинные функции, глубокое вложение, волшебные числа
- **Лучшие практики** — обеспечивают соблюдение типов TypeScript, обработку ошибок, конвенции именования
- **Поддержка SARIF** — результаты экспорта в формате отраслевого стандарта
### 📝 PR-ассистент / PR 助手
- **Автогенерация описаний PR** из git diff
- **Умное резюме** изменений с оценкой риска
- **Автоматический PR-обзор** с предложениями в строке
- **Сменный ходок** — систематически ориентируйтесь в изменениях







### ⚡ Генерация кода / 代码生成
- **Движок шаблонов** — расширяемые шаблоны кода с переменными и логикой
- **Spec parser** — разбор спецификаций JSON/YAML/естественного языка
- **Конструктор кода** — генерировать TypeScript, JavaScript, Python и другие
- **Встроенные шаблоны** — функции, классы, интерфейсы, компоненты React
### 📚 Documentation Automation / 文档自动化
- **Генерация API-документации** — извлечение JSDoc и типов из исходного кода
- **README generator** — создание профессиональных README из метаданных
- **Генератор Changelog** — сборка журналов изменений из истории git
- **Мультиформатный вывод** — Markdown, HTML, JSON
### 🔗 GitHub Integration / GitHub 集成
- **Webhook handler** — обработка событий GitHub
- **GitHub Actions** — готовые к использованию рабочие процессы CI
- **GitHub App** — программный доступ к API
