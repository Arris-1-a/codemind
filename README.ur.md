🧠 > انٹیلیجنٹ ڈیولپمنٹ اسسٹنٹ — AI پر مبنی کوڈ ریویو، پی آر تجزیہ، کوڈ جنریشن، اور ڈاکیومنٹ آٹومیشن ٹولز
Codemind ایک جامع AI سے چلنے والا ڈیولپمنٹ ٹول کٹ ہے جو آپ کے ترقیاتی ورک فلو کو آسان بنانے کے لیے ڈیزائن کیا گیا ہے۔ یہ متعدد AI فراہم کنندگان (OpenAI، Anthropic، DeepSeek، مقامی ماڈلز) کے ساتھ انضمام کرتا ہے تاکہ ذہین کوڈ جائزہ، خودکار PR مینجمنٹ، کوڈ جنریشن، اور دستاویزات کی خودکاری فراہم کی جا سکے۔
## ✨ خصوصیات / 功能特性
### 🔍 AI Code Review / AI 代码审查
- **سیکیورٹی اسکیننگ** — ہارڈ کوڈڈ رازوں کا پتہ لگانا، SQL انجیکشن، XSS، راستہ عبور کرنا
- **کارکردگی کا تجزیہ** — سنک آپریشنز، میموری لیکس، غیر مؤثر پیٹرنز کی شناخت
- **کوڈ کی بو کی دریافت** — فلیگ لانگ فنکشنز، گہرا گھونسلہ بنانا، جادوئی نمبرز
- **بہترین طریقہ کار** — ٹائپ اسکرپٹ اقسام، ایرر ہینڈلنگ، نام رکھنے کے اصولوں کو نافذ کرنا
- **SARIF سپورٹ** — برآمد کا نتیجہ صنعت کے معیاری فارمیٹ میں ہوتا ہے
### 📝 پی آر اسسٹنٹ / پی آر 助手
- **خودکار طور پر پی آر کی وضاحتیں** گٹ ڈیف سے
- **خطرے کی تشخیص کے ساتھ تبدیلیوں کا سمارٹ خلاصہ**
- **خودکار PR جائزہ** ان لائن تجاویز کے ساتھ
- **چینج واکر** — تبدیلیوں کے درمیان منظم طریقے سے نیویگیٹ کرنا







### ⚡ کوڈ جنریشن / 代码生成
- **ٹیمپلیٹ انجن** — متغیر اور منطق کے ساتھ قابل توسیع کوڈ ٹیمپلیٹس
- **Spec parser** — پارس JSON/YAML/قدرتی زبان کے اسپیکس
- **کوڈ بلڈر** — ٹائپ اسکرپٹ، جاوا اسکرپٹ، پائتھن، اور مزید تیار کرتا ہے
- **بلٹ ان ٹیمپلیٹس** — فنکشنز، کلاسز، انٹرفیسز، ری ایکٹ کمپونینٹس
### 📚 Documentation Automation / 文档自动化
- **API دستاویز کی جنریشن** — ماخذ سے JSDoc نکالنا اور ٹائپس کو نکالنا
- **README جنریٹر** — میٹا ڈیٹا سے پیشہ ورانہ READMEs تیار کریں
- **چینج لاگ جنریٹر** — گٹ ہسٹری سے چینج لاگز بناتا ہے
- **ملٹی فارمیٹ آؤٹ پٹ** — مارک ڈاؤن، HTML، JSON
### 🔗 GitHub Integration / GitHub 集成
- **Webhook ہینڈلر** — GitHub ایونٹس کو پروسیس کرنا
- **GitHub Actions** — استعمال کے لیے تیار CI ورک فلو
- **GitHub ایپ** — پروگراماتی API رسائی
