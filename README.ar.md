# 🧠 عقل الكود
**مساعد تطوير مدعوم بالذكاء الاصطناعي — مراجعة الكود، تحليل العلاقات العامة، توليد الكود، أتمتة التوثيق**

🧠 مساعد تطوير > الذكي — مراجعة الشيفرة، تحليل العلاقات العامة، توليد الكود، وأتمتة المستندات بالذكاء الاصطناعي
كودمايند هو مجموعة أدوات تطوير شاملة مدعومة بالذكاء الاصطناعي مصممة لتبسيط سير العمل الخاص بك في التطوير. يتكامل مع عدة مزودي ذكاء اصطناعي (OpenAI، Anthropic، DeepSeek، نماذج محلية) لتوفير مراجعة ذكية للشيفرة، إدارة علاقات عامة آلية، توليد الشيفرة، وأتمتة الوثائق.
## ✨ الميزات / 功能特性
### 🔍 مراجعة شيفرة AI / AI 代码审查
- **مسح الأمان** — اكتشاف الأسرار المشفرة الصلبة، حقن SQL، XSS، عبور المسار
- **تحليل الأداء** — تحديد عمليات المزامنة، تسربات الذاكرة، الأنماط غير الفعالة
- **كود يشم الكشف** — علم الوظائف الطويلة، تعشيش عميق، أرقام سحرية
- **أفضل الممارسات** — تطبيق أنواع TypeScript، التعامل مع الأخطاء، وقواعد التسمية
- **دعم SARIF** — نتائج التصدير بصيغة قياسية في الصناعة
### 📝 مساعد العلاقات العامة / العلاقات العامة 助手
- **توليد أوصاف العلاقات العامة تلقائيا** من git diff
- **تلخيص ذكي** للتغييرات مع تقييم المخاطر
- **مراجعة علاقات عامة آلية** مع اقتراحات متداخلة
- **مشي التغيير** — يتنقل بشكل منهجي عبر التغييرات







### ⚡ توليد الشيفرة / 代码生成
- **محرك القالب** — قوالب كود قابلة للتوسعة مع المتغيرات والمنطق
- **محلل المواصفات** — تحليل مواصفات JSON/YAML/اللغة الطبيعية
- **منشئ الكود** — توليد TypeScript، JavaScript، Python، والمزيد
- **القوالب المدمجة** — الدوال، الفئات، الواجهات، مكونات React
### 📚 أتمتة التوثيق / 文档自动化
- **توليد مستندات API** — استخراج JSDoc والأنواع من المصدر
- **مولد README** — إنشاء ملفات README احترافية من البيانات الوصفية
- **مولد سجل التغيير** — بناء سجلات التغييرات من سجل git
- **خرج متعدد الصيغ** — ماركداون، HTML، JSON
### 🔗 تكامل GitHub / GitHub 集成
- **معالج Webhook** — معالجة أحداث GitHub
- **إجراءات GitHub** — سير عمل CI جاهز للاستخدام
- **تطبيق GitHub** — وصول برمجي إلى واجهة برمجة التطبيقات
